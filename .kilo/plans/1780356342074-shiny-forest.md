# Plan for Multi-Folder Workspace Setup

## Goal
Create a multi-folder workspace separating UI from core engine by extracting and organizing code from two zip files.

## Steps

### 1. Extraction & Preparation
- Create temporary directory: `_temp_extract`
- Unzip `King-main (4).zip` into `_temp_extract`
- Unzip `10kant-main (1).zip` into `_temp_extract`

### 2. Scaffolding the Master Workspace
In root directory, create:
```
./
├── canvas/    (Visual UI)
├── pepper/    (Chat UI)
└── ra1/       (Engine & Infra)
    ├── api/
    ├── packages/types/src/
    ├── services/
    ├── infra/
    └── reference/
```

### 3. Populate canvas & pepper (Frontends)
- Move `_temp_extract/10kant-main/apps/canvas` to `./canvas/` (ensure no backend logic remains)
- From `_temp_extract/10kant-main/`, locate LibreChat application/configuration files and move entirely to `./pepper/`

### 4. Assemble ra1 (Core Engine & Backend)
- **API Foundation**: Move King Fastify backend source code to `ra1/api/`
- **Logic Migration**: Identify node execution logic/backend algorithms from 10kant and move to `ra1/api/services` or `ra1/api/controllers`
- **Housekeeping - Route Wiring**: Open `ra1/api/src/index.ts` (or main entry point). Ensure `vaultRoutes` is imported and mounted to central router middleware chain
- **Reference Docs**: Move model-engine and docs folders from both repos to `ra1/reference/`

### 5. Assemble Shared Types (ra1/packages/types)
- Merge TypeScript definitions from King's `packages/types` and 10kant's `packages/shared` into `ra1/packages/types/src/index.ts`
- Explicitly define and export core shapes: `User`, `Credential`, `ApiResponse`
- Ensure `ra1/api/package.json` correctly points to this local types workspace

### 6. Assemble Infrastructure (ra1/)
- **Configs**: Move King's Docker configs to `ra1/infra/docker/`
- **Services**: Move 10kant's LiteLLM configuration (`config.yaml`) and Postgres multi-db initializations to `ra1/services/`
- **Environment Consolidation**: Extract `.env` / `.env.example` keys from both repos and generate single, logically grouped `ra1/.env.example`
- **Master Docker-Compose**: Create `ra1/docker-compose.yml`. Merge King's services (API, Clickhouse, etc.) with 10kant's LiteLLM and Langfuse services. Ensure volume mounts point correctly to new `services/` and `infra/` paths, and Langfuse wired to Postgres container on internal network

### 7. Cleanup
- Delete `_temp_extract` folder entirely

## Output Definition of Done
- Confirm file operations complete
- Verify directories match target architecture
- Confirm `docker-compose.yml` and `index.ts` successfully modified
