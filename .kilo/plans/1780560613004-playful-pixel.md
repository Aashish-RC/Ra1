# RA1 Runnable from Docker Compose Up Plan

## Overview
This plan addresses all issues to make RA1 runnable from `docker compose up -d` without pre-setup, including:
1. Making Infisical optional in bootstrap
2. Making secrets schema fields optional with defaults
3. Wrapping non-essential infra connections in try/catch
4. Making Infisical service methods graceful when client unavailable
5. Fixing docker-compose VITE_API_URL for browser accessibility
6. Adding LITELLM_MASTER_KEY to API service environment
7. Updating .env.example with quick start section
8. Fixing API Dockerfile to work with pnpm workspace
9. Updating SETUP.md with correct structure and quick start
10. Reordering hooks in ModelTestPage.tsx

## Changes

### 1. apps/api/src/config/bootstrap.ts
Make Infisical optional. If INFISICAL_SERVICE_TOKEN or INFISICAL_SYSTEM_PROJECT_ID is missing, skip Infisical entirely and load secrets directly from process.env. Do not throw. Log a warning.

### 2. apps/api/src/config/secrets.ts
Make every field in systemSecretsSchema optional with .optional() or .default('') so partial parsing never throws.

### 3. apps/api/src/index.ts
Wrap each non-essential connect* call in its own try/catch that logs a warning and continues. Only connectPostgres() and connectValkey() should remain fatal.

### 4. apps/api/src/services/infisical.service.ts
When getClient() returns null (no service token), make methods return appropriate defaults instead of throwing:
- listKeys → return []
- resolveKey → return null
- saveKey → throw with clear message: "Vault unavailable: set INFISICAL_SERVICE_TOKEN to store keys"
- revokeKey → return false

### 5. docker-compose.yml
Two fixes:
- Fix A: Change canvas VITE_API_URL to use ${VITE_API_URL:-http://localhost:3001}
- Fix B: Add LITELLM_MASTER_KEY to API service environment block

### 6. .env.example
Add a # ── Quick start (no Infisical required) ── section at the top with the minimum vars needed to boot.

### 7. apps/api/Dockerfile
Update to properly handle pnpm workspace by copying workspace root files first.

### 8. SETUP.md
Rewrite Quick Install section to reflect actual repo structure and new minimal boot path.

### 9. apps/canvas/src/pages/ModelTestPage.tsx
Reorder hooks: move loadScores, loadCooldowns, and their mount useEffect to before sendMessage.

## Verification Steps
After implementing all changes:
1. cp .env.example .env
2. Fill in the 5 Quick start values (POSTGRES_PASSWORD, LITELLM_MASTER_KEY, JWT_SECRET, INFISICAL_ENCRYPTION_KEY, INFISICAL_AUTH_SECRET)
3. docker compose up -d canvas api postgres valkey litellm
4. Open http://localhost:5173 → click "Model Test" tab
5. Add a provider key in the Vault section → Test → send a chat message

All services should start successfully without requiring Infisical, ClickHouse, Qdrant, Ollama, MinIO, Langfuse, LibreChat, or MongoDB for basic Model Test functionality.
